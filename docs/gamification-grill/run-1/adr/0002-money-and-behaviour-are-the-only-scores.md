# Money and behaviour proof are the only scores; no parallel reward currency, no ranking

**Status:** proposed

We considered satisfying "add gamification" with the conventional layer — XP, points, levels, badges
and a leaderboard — and decided against it. The game's only scores stay **money (◈), the Named Goal,
the Credit Score and the three Behavioural Measures**; a **Milestone grants nothing** (no money, no
content, no power), and there is **no comparison to any other player**.

## Considered options

- **A parallel currency (XP/points/gems).** The documented failure mode: reward attaches to completing
  content, not to financial competence; expected tangible rewards reliably undermine intrinsic
  motivation (Deci, Koestner & Ryan, 1999), and a points layer would compete with the game's own
  premise that the money *is* the score.
- **Leaderboards.** Reward luck and starting position over capability, and the seeded draw makes runs
  only partially commensurable. Already out of scope in the project map.
- **Diegetic progression (chosen).** Progression is expressed with the game's own vocabulary —
  milestones, a year in review, a private cross-Run record — so a player optimising for it is
  optimising for behaviour the game already teaches.

## Consequences

- Every Milestone must derive from a Behavioural Measure or a Turning Point, never a raw balance,
  which keeps the Better-Choices Proof the single source of truth.
- There is deliberately nothing to farm and nothing to lose, so no loss-framed streak or daily-return
  pressure is possible by construction.
- If a future stakeholder asks "where is the XP?", this ADR is the answer; the boundary is a
  decision, not an oversight.
